❓ 怎么看 · 指令表 · 名词解释（小人计算机 = Little Man Computer，LMC）

指令表（三位机器码 ↔ 助记符）

带信箱地址的指令（1xx、2xx、3xx、5xx、6xx、7xx、8xx）：首位是操作码，后两位是信箱地址；4xx 未定义；901、902、000 按整个三位数识别。

机器码助记符作用
1xxADDACC ← ACC + 信箱 xx 里的数
2xxSUBACC ← ACC − 信箱 xx 里的数
3xxSTA信箱 xx ← ACC（存储）
5xxLDAACC ← 信箱 xx 里的数（装入）
6xxBRAPC ← xx（无条件跳转，不看 ACC）
7xx / 8xxBRZ / BRPACC = 0 / ACC ≥ 0（含 0）时 PC ← xx；否则 PC 保持顺序地址
901INP输入篮的下一个数 → ACC
902OUTACC → 输出篮（ACC 不变）
000HLT停机
—DAT数据声明：不是指令，只是预先在信箱里放一个数

名词

  • CPU 中央处理器；ALU 算术逻辑单元，负责加减。
  • ACC 累加器：存放正在计算的数。
  • PC 程序计数器：下一条指令所在的信箱号，不是“正在执行”的那条。
  • IR 指令寄存器：存放取来的整条指令（三位数）。
  • MAR 存储器地址寄存器；MDR 存储器数据寄存器。
  • 地址总线 / 数据总线 / 控制总线：哪个信箱 / 送什么值 / 设备做什么。
  • RAM 内存：LMC 有 100 个信箱（00–99），每个装一个三位数。图中只画出本例用到的 00–06，其余 07–99 都是 000。

三条总线各管一件事：橙色地址总线＝哪个信箱；铜红数据总线＝送什么值；蓝绿虚线控制总线＝设备做什么（MEM_READ 读内存 / MEM_WRITE 写内存 / IO_READ 读输入 / IO_WRITE 写输出）。ADD 05 加的是信箱 05 里的数，不是 5。

图中控制总线只画本模型由控制单元发出的这 4 条命令。真实计算机的控制总线还有时钟、中断、总线请求 / 应答等线，其中有些由设备发回 CPU，并不都是单向的。PC + 1、译码、ALU 运算和分支改 PC 属于 CPU 内部控制，不经过外部控制总线，所以这些微步观察栏显示“空闲”。

操作：按“暂停”会立刻完成正在走的这一微步，停在步与步之间，寄存器不再变化；再按播放从下一微步继续。焦点在按钮上时 ← → 也能后退/前进。
